# 8.22 студия — сайт салона красоты

Многостраничный сайт студии красоты 8.22 (Минск, просп. Дзержинского, 34): главная, услуги и цены с фильтром, о студии, запись и контакты. Мягкий светлый дизайн в тонах шёлка, шрифты Cormorant Garamond и Montserrat. Чистые HTML, CSS и JS без сборки. Без раздела галереи, фото распределены по страницам.

## Что менять
Всё в `js/data.js`: `SITE` (адрес, телефон, Instagram) и `GROUPS` (разделы прайса). Строка услуги: `[название, цена, пояснение или «вместо X Br»]`.

## Публикация на GitHub Pages
Залей содержимое папки в корень репозитория (не `.zip`), затем **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Сайт сделал [Lexey](https://t3trix-hub.github.io/t3trix-portfolio/). Логотип, фото и названия принадлежат студии.
